# Emotion Page MoodAI

Браузерное расширение, которое определяет эмоциональную окраску текстов на веб-странице (посты в соцсетях, новости) и показывает результат прямо на странице: цветная рамка вокруг каждого поста и панель с главной эмоцией страницы.

Модель различает 28 эмоций (набор GoEmotions): радость, страх, печаль, гнев, благодарность, нейтрально и другие. Один текст может получить несколько эмоций одновременно.

## Как это работает

```
текст поста -> эмбеддинг (LaBSE-en-ru, 768 чисел) -> MLP -> вероятности 28 эмоций -> показ на странице
```

- Расширение (JavaScript) собирает тексты со страницы и отправляет их на сервер.
- Сервер (FastAPI) считает эмбеддинги и вероятности эмоций.
- Главная эмоция страницы: среднее вероятностей по всем постам, затем эмоция с максимальным значением.

## Результаты

Проверка на отложенных 20% датасета GoEmotions (10 853 примера), порог 0.25 подобран на этой же выборке:

| Метрика  | Значение |
|----------|----------|
| micro-F1 | 0.515    |
| macro-F1 | 0.373    |

Проверка на русском: 25 фраз, написанных вручную (`check_russian.py`), Top-1 = 68%, Top-3 = 80%.

## Ограничения

- Классификатор обучен на английском датасете GoEmotions. На русском тексте он работает за счёт того, что энкодер LaBSE помещает фразы с одинаковым смыслом на разных языках рядом. Проверка на русском проведена только на небольшом наборе фраз.
- Редкие эмоции определяются хуже (например, гнев).
- Это не медицинский инструмент: модель оценивает эмоциональную окраску текста и не диагностирует стресс, тревогу или другие состояния.

## Установка

Нужен Python 3.9.

```
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Скачайте энкодер [cointegrated/LaBSE-en-ru](https://huggingface.co/cointegrated/LaBSE-en-ru) в папку `encoder`:

```python
from sentence_transformers import SentenceTransformer

SentenceTransformer("cointegrated/LaBSE-en-ru").save("./encoder")
```

Проверка: `print(model)` должен показывать слои Transformer, Pooling (cls), Dense и Normalize, размерность 768.

Веса классификатора (`mlp_multilabel_emotions.pth`) лежат в репозитории.

## Запуск

1. Запустите сервер:
   ```
   uvicorn api:app --host 127.0.0.1 --port 8000
   ```
2. Установите расширение в Chrome: откройте `chrome://extensions`, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку репозитория.
3. Откройте страницу с текстами (например, ленту соцсети). Расширение проанализирует посты и покажет эмоции.

## API

| Эндпоинт                     | Что делает                                                 |
|------------------------------|------------------------------------------------------------|
| `POST /predict`              | эмоции одного текста                                       |
| `POST /predict_many`         | эмоции списка текстов                                      |
| `POST /predict_many_with_page` | эмоции списка текстов и главная эмоция страницы          |

Пример:

```
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "какая же красивая была осень"}'
```

Ответ содержит список эмоций выше порога (`emotions`) и вероятности всех 28 эмоций (`probabilities`).

## Обучение с нуля

Данные: GoEmotions (`train.tsv`, `dev.tsv`, `test.tsv`). Скрипты запускаются по порядку:

1. `embedding.py` считает эмбеддинги и создаёт `all_data.pkl`.
2. `multi-hot.py` превращает номера эмоций в векторы из 28 нулей и единиц. Запускать один раз после `embedding.py`.
3. `train_mlp.py` обучает классификатор и сохраняет веса в `mlp_multilabel_emotions.pth`.

Оценка качества:

- `evaluate.py` считает micro-F1 и macro-F1 на отложенной выборке.
- `find_threshold.py` перебирает пороги классификации.
- `check_russian.py` проверяет модель на русских фразах.

Файл `1.tsv` это небольшая выборка, которая использовалась для быстрой проверки пайплайна.

## Приватность

Расширение отправляет текст страницы на сервер. В текущей версии сервер запускается локально, поэтому тексты не покидают компьютер.
